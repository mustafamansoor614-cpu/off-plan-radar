This reads Meta's public Ad Library page server-side — no login, no official API (Meta's Ad Library API doesn't cover commercial ads outside the EU/UK). That also means it's inherently best-effort: Meta can change their page format or rate-limit this at any time, which would need a small update to netlify/functions/fetch-ads.js. Built for personal competitive research — not intended to be run at scale or resold. See README.md for setup and details.
